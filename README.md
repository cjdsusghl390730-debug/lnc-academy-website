# L&C 소통 아카데미 정적 홈페이지

HTML5, CSS3, Vanilla JavaScript만으로 만든 반응형 정적 홈페이지입니다. 별도의 빌드 과정이나 외부 라이브러리가 필요하지 않습니다.

## 1. 실행 방법

`index.html`을 직접 열거나, 사이트 폴더에서 아래 명령을 실행합니다.

```powershell
python -m http.server 4173
```

또는:

```powershell
py -m http.server 4173
```

브라우저에서 `http://localhost:4173/`을 엽니다. 서버를 종료할 때는 터미널에서 `Ctrl + C`를 누릅니다.

## 2. 공개 홈페이지 구조

공개 메뉴는 다음 두 항목만 사용합니다.

- 아카데미 소개 → `index.html`
- 프로그램 안내 → `programs.html`

위치 및 지점 관련 페이지는 현재 공개 홈페이지에서 사용하지 않습니다.
기존 파일은 추후 활용 가능성을 위해 보관되어 있습니다.

## 3. 파일 구조

```text
lnc-academy/
├─ index.html                     아카데미 소개
├─ programs.html                  프로그램 안내
├─ location.html                  비공개 보관 페이지(noindex, nofollow)
├─ locations/                     비공개 지점 페이지 보관 폴더
│  ├─ pyeongtaek.html
│  ├─ pyeongtaek-station.html
│  └─ pyeongtaek-segyo.html
├─ assets/
│  ├─ css/style.css               전체 디자인과 반응형 스타일
│  ├─ js/main.js                  메뉴, 헤더, 앵커, 라이트박스
│  └─ images/
│     ├─ final/                   공개 페이지에 적용한 운영 이미지
│     ├─ temp/                    이전 임시 이미지 보관 폴더
│     ├─ placeholders/            이전 플레이스홀더 보관 폴더
│     └─ location/                비공개 위치 페이지 이미지 보관 폴더
├─ DESIGN_SYSTEM.md               확정된 디자인 기준과 변경 금지 원칙
└─ README.md
```

## 4. 프로그램 과정 기준

공식 과정은 다음 구조만 사용합니다.

```text
입문·기초 과정 — 4개월
심화 과정 — 4개월
총 8개월
```

세부 커리큘럼과 과목은 확정 전까지 임의로 추가하지 않습니다.

## 운영 이미지 안내

공개 홈페이지의 이미지는 모두 프로젝트 내부 운영 이미지가 적용되어 있습니다.

운영 이미지 폴더:
`assets/images/final/`

이미지를 교체할 때는 기존 파일명과 비율을 유지하거나,
HTML의 이미지 경로만 교체해주세요.

이미지 교체 과정에서 섹션 높이, 여백, 이미지 비율,
텍스트 위치 및 전체 디자인 톤은 변경하지 않습니다.

이미지별 권장 비율:

- Hero 이미지: 현재 Hero 영역 비율 유지
- 가로 본문 이미지: 현재 CSS의 `aspect-ratio` 유지
- 과정 이미지: 입문·기초 및 심화 과정 모두 `3 / 2` 비율 유지
- 프로그램 미리보기 이미지: 데스크톱 `4 / 5`, 반응형에서 현재 CSS 비율 유지
- 마무리 이미지: 전체 너비 가로형

모든 공개 이미지는 프로젝트 내부 파일이므로 외부 이미지 URL에 의존하지 않습니다. 장식용 이미지는 빈 대체 텍스트를 사용하고, 의미가 있는 이미지에는 용도에 맞는 대체 텍스트를 유지합니다.

## 5. 수강생 후기 추가 방법

`programs.html`의 `STUDENT REVIEWS` 영역에 실제 후기 카드 구조를 추가합니다. 실제 후기와 공개 동의를 확인하기 전에는 임의의 이름이나 후기를 넣지 않습니다.

## 6. 확정되지 않은 정보

푸터의 대표 문의, 이메일, 운영 시간은 아직 확정되지 않아 `준비 중`으로 유지되어 있습니다. 확정된 정보만 모든 공개 페이지에 동일하게 반영합니다.

## 7. 배포 전 확인 체크리스트

- [ ] `index.html`, `programs.html`이 정상적으로 열리는지 확인
- [ ] 공개 메뉴가 아카데미 소개와 프로그램 안내 두 항목인지 확인
- [ ] 공개 페이지에서 위치 및 지점 페이지로 이동하는 링크가 없는지 확인
- [ ] 위치 관련 보관 페이지에 `noindex, nofollow`가 있는지 확인
- [ ] Hero 높이와 텍스트 정렬이 두 페이지에서 동일한지 확인
- [ ] 모든 이미지가 로컬에서 표시되고 깨진 경로가 없는지 확인
- [ ] 입문·기초 및 심화 과정 이미지의 크기와 비율이 동일한지 확인
- [ ] 1440, 1280, 1024, 768, 430, 390, 360px에서 가로 스크롤이 없는지 확인
- [ ] 데스크톱과 모바일에서 메뉴가 열리고 닫히는지 확인
- [ ] 키보드만으로 메뉴와 링크를 사용할 수 있는지 확인
- [ ] 브라우저 개발자 도구 콘솔에 JavaScript 오류가 없는지 확인
- [ ] 실제 수강생 후기와 공개 동의 확인 후 후기 추가
- [ ] 한글이 UTF-8로 표시되는지 확인

## 8. 디자인 변경 원칙

사용자가 디자인 변경을 명확하게 요청하지 않았다면 기존 디자인 톤을 변경하지 않습니다.

```text
콘텐츠 수정은 콘텐츠만,
기능 수정은 기능만,
이미지 수정은 이미지만 변경합니다.
```

세부 기준은 `DESIGN_SYSTEM.md`를 따릅니다.
